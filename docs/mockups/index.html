Pilihan Arah Desain Mockup Uangku

Tiga arah desain visual self-contained berukuran 390px (mobile viewport) berdasarkan referensi Copilot iOS, Sumeria iOS, dan prinsip DBD/PRD.

Opsi A

Clean Card Modern

Inspirasi Copilot iOS: Kartu modular berlapis, aksen biru kobalt, keypad bulat empuk, chart donut ringkas.

  • Karakter: Ramah, kontemporer, visual santai
  • Input Tunai: Keypad keypad bulat besar + chip empuk
  • Hierarki: Angka hero tegas di kartu terpisah
  • Status Listener: Banner hijau/kuning elegan di atas

Opsi B

Editorial Warm Minimal

Inspirasi Sumeria iOS: Tipografi berkarakter (serif), palet batu hangat (stone/warm white), garis pemisah halus.

  • Karakter: Elegan, buku kas personal, tenang
  • Input Tunai: Keypad kotak rapat + chip persegi
  • Hierarki: Angka headline raksasa tanpa kartu tebal
  • Status Listener: Subbar status tipis terintegrasi

Opsi C

Compact High-Density

Inspirasi Terminal & Ledger: Monospace, border hitam tegas, kepadatan data tinggi, tanpa dekorasi grafis.

  • Karakter: Fungsional maksimal, developer-first, tajam
  • Input Tunai: Keypad flat tegas, grid kategori padat
  • Hierarki: Baris-baris ledger padat muat banyak item
  • Status Listener: Header status hardware ringkas
